## The logic, as approved (version `2oyXahw1`)

Within each IF / ELSE IF / ELSE chain the first true test is taken; each part of a split is decided separately and held at its share. `Nd` is N trading days. RSI is Wilder's. Decided on prices a few minutes before the close (measured about 15:51-15:54 ET, results.md addendum 50; Composer does not publish the time).

```
IF 10d moving-average price of TQQQ > 20d moving-average price of TQQQ:
  IF RSI(TQQQ, 10d) > 80:
    the bottom 1 by 10d RSI of UVXY, VIXY, VIXM
  ELSE IF price of SPY > 200d moving-average price of SPY:
    the top 1 by 10d RSI of TQQQ, UPRO, UDOW, SSO, TNA
  ELSE:
    BIL
ELSE IF RSI(TQQQ, 10d) < 30:
  the bottom 1 by 10d RSI of TECL, QLD, LABU, USD, SMH
ELSE IF RSI(SOXL, 10d) < 30:
  BIL
ELSE IF price of TQQQ < 20d moving-average price of TQQQ:
  BIL
ELSE IF price of SPY > 200d moving-average price of SPY:
  the top 1 by 10d RSI of TQQQ, UPRO, UDOW, SSO, TNA
ELSE:
  BIL
```
