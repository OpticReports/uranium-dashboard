📊 Sharpe Ratio & Risk-Adjusted Return

Sharpe Ratio Formula

Risk-Adjusted Return Metric
Sharpe = (E[R_portfolio] - Rf) / σ_portfolio

Where:
• E[R_portfolio] = Expected return (with uranium)
• Rf = Risk-free rate (4% 10-yr treasury)
• σ_portfolio = Portfolio volatility (standard deviation of returns)

🎲 Monte Carlo Simulation Methodology

Why Monte Carlo?

Historical analysis assumes past volatility = future volatility. Wrong.
Monte Carlo generates 10,000 future scenarios reflecting true uncertainty distribution.

Simulation Parameters

Parameter Value Justification
Simulations 10,000 Convergence threshold; beyond 5,000 results stabilize
Time Horizon 1 year Matches rebalancing frequency; tactical allocation decision
Drift (Mean Return) 16.8% (portfolio) Conviction-weighted thesis expectations
Volatility 21.8% (portfolio) Covariance-adjusted across all holdings
Correlation Shocks ±0.10 random Reflects tail events where correlations spike

Simulation Algorithm

for i = 1 to 10000: // Draw random daily returns for 252 trading days for day = 1 to 252: dW ~ Normal(0, 1) // Wiener process random draw // Geometric Brownian Motion for each asset for each_asset in portfolio: R_daily = μ/252 + σ/√252 × dW price_daily = price_prev × exp(R_daily) // Account for correlation between assets if random_event and correlation_spike: apply_shock = uniform(-0.10, +0.10) correlations += apply_shock // End of year portfolio value returns[i] = (portfolio_final - portfolio_initial) / portfolio_initial // Record metrics final_values[i] = portfolio_final max_drawdown[i] = track_intra_year_dd() // Analyze results percentile_5 = returns sorted, grab 5th percentile (VaR) percentile_25 = ... median = percentile_50 percentile_75 = ... percentile_95 = returns sorted, grab 95th percentile (upside) Expected_Return = mean(returns) Volatility = std(returns) Sharpe = (Expected_Return - Rf) / Volatility

Model Limitations (Honesty Statement)

⚠️ What This Model CANNOT Do:

1. Predict exact timing: Model says uranium will reach $110-130/lb, but not when (could be 18mo or 5yr)
2. Account for black swan events: Nuclear accident, geopolitical war, policy reversal—these have tail impacts beyond normal distributions
3. Model behavioral/sentiment factors: Model assumes rational pricing; FOMO bubbles aren't capturable
4. Capture regime changes: If fundamental macro regime shifts (e.g., global recession), model assumptions break
5. Real-time rebalancing: Model is a guidance tool; actual execution has friction costs (1-2% slippage)

Remedy: Treat as decision framework, not prophecy. Rerun quarterly with updated data. Monitor conviction score weekly.
